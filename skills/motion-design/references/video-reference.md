# Closely recreate a supplied video

Unless the user requests loose inspiration, treat the supplied clip as the structure to preserve. Change the subject and copy within it. Matching a palette while inventing a new storyboard is not close recreation.

## Observe and map

Inspect the clip through its ending. Make a short source-to-replacement map at its natural beats: approximate time, dominant object/type and screen coverage, framing or crop, movement direction and scale change, transition, replacement content. Check frames around major transitions; automated analysis and isolated stills can misread motion. Mark unobserved details instead of inventing precise timing.

Keep the original duration/aspect, scene order, relative holds, composition, typography hierarchy, camera path and transition mechanics unless the user asks otherwise or a verified constraint prevents it. Fit concise new copy to the existing text footprints. Preserve the communication purpose through those substitutions; simplify the message before adding scenes, UI panels or explanatory steps. Note necessary departures. Do not force an answer panel into a reference that has none.

## Choose the route and prompt

For changes mostly limited to words, branding or subject inside an existing composition, inspect a supported whole-video edit route first. For broader reconstruction, use video conditioning and describe what must remain. Route based on the actual transformation and current media roles; subject motion transfer from driving video to image references is a different operation from graphic/type editing. Do not promise frame-identical output from a generative tool.

Attach the original clip itself. Do not substitute the previous adaptation as the sole reference when it already lost the source choreography. A source prompt is optional provenance, not a requirement for this path.

Keep the creative prompt focused on preserving the source and mapping substitutions. Avoid a competing new storyboard. State exact replacement copy and remove original-brand remnants. Record how music, effects and speech should be handled separately; do not assume a visual reference authorizes reproducing a speaker's voice.

## Compare before delivery

Compare source and result at corresponding moments: does the hero occupy similar screen space, does the camera travel the same direction and distance, do scale changes and transitions happen at similar moments, and are the same holds retained? Check the new message and exact text separately. A color match or readable brand is not a motion-fidelity pass. Disclose uninspected temporal/audio behavior.

If the result drifts, correct the mismatch using the original clip and the bounded full-film revision policy in [production.md](production.md). If it remains distant, report that limitation rather than relabeling it a successful recreation. Keep any exact compositing fallback explicit.
