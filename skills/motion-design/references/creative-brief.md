# Prompt format and supporting brief

For a selected preset, read its archived original prompt in full. Keep that original format and section order for the adapted creative prompt. Do not translate it into a different master-brief skeleton. Carry over its shot descriptions, movement amplitudes, transitions, design rules and audio structure with targeted substitutions.

Keep production metadata outside the creative prompt: source prompt path/hash, chosen model and native settings, reference assets/roles, evidence links, exact-copy inventory, departures and review/submission status. The full prompt must stand alone when accompanied by its declared references. Do not add local render scripts or mandatory compositing directions to a generative prompt.

For an original concept without a source template, a useful prompt structure is:

```text
[Duration, aspect ratio, film type, subject and one-sentence story]

design world:
[Concrete objects, palette roles, material/light behavior and typography]

motion rules:
[Camera travel, continuity, easing, geometry, blur and text behavior]

[Contiguous timed shots or phases, with the action, camera, transition, exact copy and reading hold]

overall_soundscape:
[Specific effects tied to visible actions; state whether speech exists]

non_diegetic_music:
[Instrumental character, tempo, progression and ending; or explicit silence]

[Reference roles only if references are actually planned]
```

Use music and synchronized effects by default for new launch/motion films; new narration requires a separate choice. Preserve explicit project silence. Audio and all visual events must fit inside the requested duration. A static final frame can have a short sound decay without extending the film.

## Timing and readability

Keep source timings unless the user requests another duration or a factual/readability problem requires an explained adjustment. Label catalog timelines that retime a source. Every interval must fit the film, without missing time or conflicting overlaps. Shots/phases are editorial units inside one generation request.

Use a compact exact-copy inventory to catch spelling, punctuation and original-brand leftovers. Keep values and qualifications readable at delivery size. Start by asking the model for the intended typography; only plan deterministic finishing when required by the task or a demonstrated failure, and disclose that change.

## References and vertical work

Choose references for a concrete purpose; zero is a valid choice. Identity references, style references and start/end frames are distinct. Research is needed for factual claims even when no visual references are attached.

For vertical delivery, recompose type, motion paths and subjects around 1080x1920, with conservative top/bottom margins. Do not crop the hero or add a fixed text column to every source shot. Record the aspect-ratio departure, retaining the original motion logic where practical.
