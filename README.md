# Higgsfield Motion Design

**Choose a look. Give it your product. Create a complete film from Codex or Claude Code.**

A shared skill that adapts detailed motion-design prompts into product launches, kinetic typography, explainers and more, then generates through Higgsfield MCP. Start with one of ten source examples or develop an original concept.

## Quick start

You need Codex or Claude Code with local skills. To generate media, connect your own Higgsfield account with access to the chosen model and enough credits or an applicable allowance. You can browse examples and draft prompts before connecting.

### Codex

Paste into Codex:

```text
$skill-installer

Install the skill from:
https://github.com/cth9191/higgsfield-motion-design/tree/main/skills/higgsfield-motion-design
```

Then use `$higgsfield-motion-design` to browse looks or describe a film.

### Claude Code

Paste into Claude Code:

```text
Install the skill from https://github.com/cth9191/higgsfield-motion-design.
Copy the complete skills/higgsfield-motion-design folder into
~/.claude/skills/higgsfield-motion-design. If it already exists,
compare it, back up local customizations, and update it.
```

Then use `/higgsfield-motion-design`. Both apps use the same skill folder.

**Connect Higgsfield separately:** follow the [setup guide](docs/setup.md#2-connect-higgsfield) for account authentication, the Claude Code MCP command, a read-only connection check and common fixes. For an existing install, update the entire skill folder, including its references and gallery.

## Try it

Start with `$higgsfield-motion-design` in Codex or `/higgsfield-motion-design` in Claude Code, then add one of these requests:

**Browse first**

```text
Show me the available motion-graphics styles with playable examples.
```

**Turn a website into a launch concept**

```text
Use the website I provide to propose a 15-second promo.
Choose a suitable preset and focus on one main product benefit.
Show me the complete adapted prompt before generating anything.
```

**Explain one idea**

```text
Use the flat vector explainer preset for a beginner-friendly,
15-second explanation of how an LLM generates an answer.
Use music and synchronized effects without narration.
Show me the full adapted prompt before generating anything.
```

**Create a product film**

```text
Use the tropical product preset to make a 15-second film for the
product photo I attach. Keep its packaging recognizable.
Use instrumental music and sound effects, with no narration.
Generate the complete film and inspect the result.
```

Asking to review the prompt first stops before images, uploads and video jobs. Asking to make the film authorizes production within your request; generations can incur charges. You can also request reference images alone.

## How it works

1. **Choose the motion.** Browse examples or describe the result you want. The assistant selects the relevant original prompt and adaptation guide.
2. **Make it about your subject.** It adapts the copy, product actions and assets while preserving the source's shot order, camera moves, materials, transitions and ending. Changes to timing or format are identified.
3. **Use references when they help.** A product photo can preserve identity; a style frame can clarify appearance. Typography and abstract concepts may need no images.
4. **Generate one complete film.** The assistant checks the current video model and submits all timed shots in one request through Higgsfield MCP, preferring a suitable Seedance model.
5. **Inspect and refine.** It checks motion, product relevance, exact copy, audio and the ending. Corrections stay within the requested budget and retry limit; unresolved issues are disclosed.

Default new campaigns target 15 seconds, 16:9 and a 30fps delivery, with instrumental music and synchronized effects. Native output fps and supported durations depend on the model. The portrait product preset and supplied-footage campaigns have their own starting settings; your explicit choices take precedence.

## What's included

- Ten presets with public source previews, archived original prompts and separate adaptation guides.
- A local gallery with filters, full prompt inspection and app-specific request copying.
- A shared workflow for browsing, prompt review, images, production and original concepts.
- Production review and correction guidance tied to each preset's defining requirements.
- A builder and GitHub Actions check for catalog consistency and source prompt hashes.

**Status:** shared workflow implemented; source catalog and templates remain version 4. Package checks and connection discovery do not establish creative reliability across all ten styles. The [validation plan](ROADMAP.md) separates completed workflow work from the real film trials and reference comparisons still needed.

Exact typography, charts, timing and product identity require output inspection. Supported finishing can repair some problems, but this package does not promise automatic pixel-exact compositing or deterministic reproduction of Higgsfield Marketing Studio. It is an independent skill, not an official Higgsfield product.

## Maintain the package

Edit `skills/higgsfield-motion-design/`, then rebuild:

```sh
python skills/higgsfield-motion-design/scripts/build_gallery.py
```

Python 3.10+ is needed only for this builder or serving the gallery. The builder checks preset IDs, linked recipes/templates, timeline coverage and archived source hashes, then refreshes the gallery and index. Commit generated changes with the source edits; CI repeats the check.

Keep original source prompts immutable. Update adaptation guides and workflow instructions for behavior changes. The source catalog/template version tracks the source library, so host-routing and README edits do not require rewriting its provenance. Installed copies are separate from the repo; update them explicitly after changes.
