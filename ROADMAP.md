# Next validation work

This is planned work, not a list of capabilities already proven across all ten presets.

## Priorities

1. Turn each preset's defining visual actions into a compact pre-generation and post-generation check, and consistently apply the checks already present.
2. Evaluate when a composed style frame or video reference improves style matching, keeping content references and style references distinct.
3. Plan an exact text/chart finishing route for fact-heavy videos when needed. Image references alone do not lock source pixels.
4. Route failures to the appropriate correction: factual graphic replacement, motion revision, or audio adjustment. Keep retries bounded and paid work within the user's authorization.

## Focused trials

- A typography announcement with a short headline.
- A product film with one real object.
- A conceptual explainer with one idea, such as autoregressive text generation.

For each trial, retain the prompt, settings, deliberate source departures, costs, and observed results in its campaign workspace. Compare the actual motion and factual content with the selected source template. Keep private assets and generation records outside this repository.

A successful generation request or a passing catalog check does not establish creative reliability. Avoid attributing an improvement solely to a model when the prompt or reference assets also changed.
